## Các bước triển khai
1. Khởi tạo thư mục (`web/`, `docs/`, `data/`, `logs/`).
2. Cấu hình cơ sở dữ liệu.
3. Đồng bộ lên kho lưu trữ.

* Các tính năng chính:
  * Quản lý cầu thủ & trận đấu.
  * Thống kê thẻ phạt, bàn thắng.
  * Phân tích log hệ thống.
